🏗️ Project Overview


This project is designed to help HR teams manage employee data efficiently with a clean and intuitive interface.

✨ Key Modules
1. Authentication System
Secure login for employees/admins
Input validation for email & password
2. Employee Dashboard
View all employees in a card-based layout
Displays:
Name & Role
Contact Information
Location
Joining Date
Skills
Status (Active/Inactive)
3. Employee Management
Add new employees
Update employee details
Delete employee records
Track employee experience and skills
🛠️ Tech Stack
Frontend: React.js / HTML / CSS / Tailwind
Backend: Node.js / Express
Database: MongoDB
Others: Axios, JWT Authentication

⚙️ Installation & Setup
# Clone the repo
git clone https://github.com/your-username/employee-management-system.git

# Go to project folder
cd employee-management-system

# Install dependencies
npm install

# Run frontend
npm run dev


# Run backend
nodemon server.js
